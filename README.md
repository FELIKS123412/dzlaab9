# Домашнее задание к работе 9

## Условие задачи
Напишите программу, выводящую на экран заданную в ДЗ лаб.6 геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа.

Предусмотреть возможность изменения размеров фигуры путем задания ее размеров в количестве символов пользователем.

Обеспечить повторение выполнения программы в цикле с постусловием do-while до тех пор, пока пользователь не захочет ее завершить.

## 1. Алгоритм и блок-схема

### Алгоритм

### Алгоритм

1. Настроить локаль `setlocale(LC_ALL, "RUS")` для корректного отображения кириллических сообщений в консоли.
2. Объявить необходимые переменные: символы контура (`contr`) и внутренней закраски (`fill`), размер (радиус) фигуры (`a`) и управляющую переменную цикла (`go`).
3. Организовать цикл `do-while` для возможности многократного запуска программы без перезапуска.
4. Запросить у пользователя и считать исходные данные:
   * символ для контура фигуры `contr`;
   * символ для внутренней закраски `fill`;
   * размер фигуры (радиус) `a`.
5. Проверить корректность введённого размера (`a < 2`):
   * **Ветвь «Да» (`a < 2`):** вывести сообщение об ошибке (`"Ошибка: размер должен быть не меньше 2."`).
   * **Ветвь «Нет» (`a >= 2`):** перейти к построчной отрисовке координатных осей и сектора окружности с помощью двух вложенных циклов `for`:
     * **Внешний цикл** по координате `y` от `a` до `-1` (с шагом `-1`).
     * **Внутренний цикл** по координате `x` от `-1` до `a` (с шагом `+1`).
     * Внутри циклов последовательно проверить принадлежность точки `(x, y)` осям координат:
       * если `x == 0` и `0 <= y < a` — вывести вертикальную ось `| `;
       * если `x == 0` и `y == a` — вывести стрелку оси Y `^ `;
       * если `y == 0` и `0 < x < a` — вывести горизонтальную ось `--`;
       * если `y == 0` и `x == a` — вывести стрелку оси X `> `;
       * если `x == 0` и `y == 0` — вывести начало координат `+ `.
     * Если точка не лежит на осях, проверить попадание в первую четверть (`x >= 0` и `y >= 0`):
       * вычислить квадрат расстояния от начала координат `r2 = x * x + y * y` и квадрат радиуса `a2 = a * a`;
       * определить условия границ фигуры: дуга окружности `acr = (abs(r2 - a2) <= a)`, биссектриса `diagonal = (x == y)` и вертикальная граница `bound = (x == 0 && y <= a)`;
       * если `(acr || diagonal || bound) && y >= x` — вывести символ контура `contr` и перейти к следующей итерации по `x` (`continue`);
       * если `r2 < a2 && y > x` — вывести символ закраски `fill` и перейти к следующей итерации по `x` (`continue`);
       * во всех остальных случаях — вывести два пробела `"  "`.
     * По завершении внутреннего цикла по `x` выполнить перевод строки (`\n`).
6. Запросить у пользователя необходимость повторного запуска и считать значение `go`.
7. Повторять цикл `do-while`, пока введённое значение не равно нулю (`while (go != 0)`).
