### Домашнее задание к работе 9

## Условие задачи
Напишите программу, выводящую на экран заданную в ДЗ лаб.6 геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа.

Предусмотреть возможность изменения размеров фигуры путем задания ее размеров в количестве символов пользователем.

Обеспечить повторение выполнения программы в цикле с постусловием do-while до тех пор, пока пользователь не захочет ее завершить.

## 1. Алгоритм и блок-схема

## Алгоритм

1. Настроить русскую локализацию (`setlocale(LC_ALL, "RUS")`) для корректного вывода сообщений.
2. Организовать цикл с постусловием `do-while` для возможности многократного выполнения программы.
3. Запросить у пользователя и считать символы `contr` (для контура фигуры) и `fill` (для внутренней закраски).
4. Запросить и считать размер фигуры (радиус) `a`.
5. Проверить корректность введённого размера: размер должен быть не меньше 2 (`a >= 2`).
6. Если размер некорректен (`a < 2`), вывести сообщение об ошибке и перейти к запросу продолжения работы.
7. Если размер корректен:
   - вывести перевод строки `\n` и инициализировать счётчик строк `y = a`;
   - запустить внешний цикл по строкам (`y >= -1`):
     - инициализировать счётчик столбцов `x = -1`;
     - запустить вложенный цикл по столбцам (`x <= a`):
       - проверить принадлежность точки `(x, y)` координатным осям:
         - если `x == 0 && y >= 0 && y < a`, вывести `"| "`;
         - иначе если `x == 0 && y == a`, вывести `"^ "`;
         - иначе если `y == 0 && x > 0 && x < a`, вывести `"--"`;
         - иначе если `y == 0 && x == a`, вывести `"> "`;
         - иначе если `x == 0 && y == 0`, вывести `"+ "`;
       - иначе, если точка находится в первой четверти (`x >= 0 && y >= 0`):
         - вычислить `r2 = x * x + y * y`, `a2 = a * a` и условия границ `acr = (abs(r2 - a2) <= a)`, `diagonal = (x == y)`, `bound = (x == 0 && y <= a)`;
         - если `(acr || diagonal || bound) && y >= x`, вывести символ контура `contr` и перейти к следующему шагу цикла;
         - если `r2 < a2 && y > x`, вывести символ закраски `fill` и перейти к следующему шагу цикла;
       - во всех остальных случаях вывести два пробела `"  "`;
       - увеличить `x = x + 1` и повторить шаг для следующего столбца;
     - после завершения строки вывести перевод строки `\n`, уменьшить `y = y - 1` и перейти к следующей строке.
8. Запросить у пользователя ввод признака продолжения работы (`go`: любая цифра — продолжить, `0` — завершить).
9. При вводе ненулевого значения повторить шаги с пункта 3, при вводе нуля завершить выполнение программы.
